# The Passport Page of a Country That Isn't There

An invented passport spread for the Republic of Kestrelia — a country that
does not exist. The data page shows holder Mira Alden Voss of Talven, with a
portrait, bilingual (Kestrelian / English) fields and a machine-readable zone;
the facing page carries arrival and departure stamps from neighbouring
Meridia, Valdoria and Ostara, all dated after the passport's issue, plus a
conditions-of-entry box and an exit-tax fee stamp that say what kind of place
Kestrelia is.

`main.ts` copies the pre-rendered `entry.png` (1024×1024) to
`$MAKEFUN_OUTPUT_DIR/entry.png`.
